# 尾延迟透镜
纯前端实测耗时观察工具。直接打开 index.html，或静态托管；无依赖、无模型API、不上传输入。

每组1–2000条，每行一个毫秒数（0–3600000，最多3位小数）或FAIL；B可留空。预算以ms计，目标1–100%。
- 成功值升序的最近秩P50/P95/P99；均值只含成功值。
- 按时成功率=时间预算内成功数/全部记录数，失败计入分母。
- 目标最小预算=升序第ceil(目标比例*总条数)个成功值；成功数不足则不可达。
- CDF以全部记录为分母，失败组不会达到100%。不推断总体SLA或未来性能。
- 显式保存/恢复；JSON备份/导入，原始CSV、分析Markdown、PNG结果卡。

示例是虚构数据，不是实测结论。对比前需统一任务、环境、并发及超时条件。

构建：node build.cjs
测试：node --test tests/core.test.cjs
封面脚本需sharp；编辑脚本的require路径以适配本机环境。
